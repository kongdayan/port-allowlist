# v0.2.0 — Customer experience and bilingual documentation

This release supports **Alibaba Cloud only**. It rebuilds the customer and operator experience without introducing another cloud provider or changing the ECS reconciler's rule-management boundaries.

- Typed React components and a shared portal store replace whole-page HTML rendering. White-list management comes first; activity, devices, logical diagrams and observed transfer charts support it.
- English and Simplified Chinese cover the UI, stable error codes, updater downloads, README and eight documentation pages per language. Business expiry defaults to UTC+8 and can be configured independently from language with an IANA time zone.
- Submitted, synchronizing, applied, removal-pending and failed states include actionable guidance. Cached status ages when polling fails. Revocations wait for successful agent processing; existing rule deletion waits for inventory confirmation.
- Current-network authorization obtains a fresh detected address. Polling preserves drafts, scroll, chart selection and expanded source groups. Mobile authorization rows become cards; light/dark appearance and reduced motion are supported.
- The public static demo uses the same UI with an isolated memory transport, clearly marked sample data and masked display addresses. It supports grant creation, expiry renewal, removal, role changes and simulated synchronization states. It never makes cloud/API requests and does not ask for a real token.
- Starlight documentation includes deployment, customer use, device setup, API, security and upgrade/recovery. Automated checks cover translation parameters, paired pages, documented commands, built links/assets/anchors, language navigation and full-text search.

Validation includes Worker/API and UI-store tests, the existing Python agent/installer suite, a real local API/browser flow, static-demo interaction tests and automated WCAG checks for customer/operator views. A clean checkout and CI must pass before release. Static-site publication does not deploy a production Worker or modify an ECS firewall.

See the [English upgrade guide](../../docs-site/src/content/docs/en/upgrade.md) or [中文升级指南](../../docs-site/src/content/docs/zh-cn/upgrade.md). Existing cloud rules do not expire while the agent is unavailable; Windows scheduled-task runtime validation remains pending.
