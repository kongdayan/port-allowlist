## Start without cloud credentials

```sh
git clone https://github.com/kongdayan/port-allowlist.git
cd port-allowlist
npm ci
npm run demo
```

Open the local URL printed by Vite. This sandbox stays in browser memory; it does not open firewall ports. To exercise the real API and persistent SQLite storage, follow the [local quick start](/port-allowlist/en/quick-start/).

## Supported today

Alibaba Cloud ECS security groups, one configured TCP port, public IPv4 grants. Cloudflare Workers and SQLite Durable Objects provide the control plane. No Terraform or other cloud adapters are included in v0.2.
