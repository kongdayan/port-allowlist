## 登录自己的专属入口

管理员会提供专属域名和一个客户访问令牌。请使用该域名：运营入口不接受客户令牌，其他客户的入口也不接受您的令牌。设备密钥仅用于自动更新，不能用于网页登录。

页面顶部可切换英文 / 简体中文、浅色 / 深色外观，也可退出登录。切换语言会保留表单输入，不改变 UTC+8 业务时区。

## 授权当前网络

1. 点击“获取当前 IP”。服务器从 Cloudflare 连接来源请求头识别地址。
2. 点击“授权此网络”，将获取到的公网 IPv4 填入授权表单；提交前仍可编辑地址、备注和到期日期。
3. 点击“添加授权”，查看同步状态。

如果使用 VPN，获取到的是 VPN 出口。办公室或家庭 NAT 后的多台设备可能共享同一份网络访问权限。如果无法获取公网 IPv4，请手动填写网络的公网 IPv4，或让设备更新脚本通过 IPv4 登记。不接受内网、保留地址和网段。

## 选择到期日

手动授权默认 30 个自然日，并受管理员配置上限约束。可填写天数、选择快捷天数或指定日期，天数与日期会联动。

**所选日期的 00:00（UTC+8）起失效**，不包含该日期当天的白天。提交前表单会明确提示。浏览器时区和界面语言不会改变到期时间；自动设备则由心跳管理租约。

在手动授权上点击“修改到期日”即可续期，或在额度允许时重新启用过期授权。可按备注或地址搜索，也可筛选有效、待同步和已过期授权。手机上每项授权以卡片展示。

## 理解状态

| 授权状态 | 含义                              | 下一步                     |
| -------- | --------------------------------- | -------------------------- |
| 已提交   | API 已接受本次变更                | 等待同步                   |
| 正在同步 | ECS 尚未确认当前授权策略          | 查看授权服务状态           |
| 已生效   | 最近的 Agent 清单覆盖了此有效地址 | 测试一个新的业务连接       |
| 删除中   | 授权已撤销，仍等待 ECS 确认处理   | 等待，或联系管理员恢复同步 |
| 同步失败 | 上报超时或同步器返回异常          | 刷新或联系管理员           |
| 已过期   | 已到业务到期时间                  | 需要时续期                 |

授权服务另有“尚未连接”“预览模式”“同步正常”“上报超时”“同步失败”状态。预览模式不会修改云规则。绿色同步状态仅确认策略同步，不代表应用登录或业务端到端健康。

## 撤销访问

点击“删除”并在确认框核对来源。删除现有防火墙规则时，会保持待处理，直到 Agent 清单确认该条规则不存在。手动授权撤销后，也可能显示“删除中”，等待成功同步确认处理。

删除自动设备当前的 IP 授权不会永久停用设备；设备下次心跳可重新登记。要停止后续更新，请选择“撤销设备”。

安全组连接跟踪可能保留已经建立的 TCP 会话。请用**新连接**验证撤销效果。共享来源或其他有效授权也可能继续允许同一网络；IP 授权不等于个人身份。

## 查看活动与架构

访问活动按来源归并已结束会话，展开可看时间、时长和字节数，需要 ECS 可选会话日志。实时连接和速率来自 socket 计数器；缺失采样显示为空白，不伪造零流量。被防火墙拒绝的连接不会到达这些会话日志。

节点图表示逻辑路径，流动连线仅表示观测到连接。节点图与架构图都不声称跟踪了真实网络路由。

客户页面不展示其他客户、服务等级、RAM 身份、安全组 ID、云凭据或原始运维诊断信息。

以上 UTC+8 示例对应默认策略。管理员可以独立配置其他业务时区，页面会显示实际时区；切换界面语言不会改变已有授权的到期时刻。
