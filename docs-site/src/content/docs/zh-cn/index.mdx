## 无需云凭据即可体验

```sh
git clone https://github.com/kongdayan/port-allowlist.git
cd port-allowlist
npm ci
npm run demo
```

打开 Vite 输出的本地地址。演示数据只保留在浏览器内存中，不会开放防火墙端口。如需体验真实 API 与 SQLite 持久存储，请按[本地快速开始](/port-allowlist/zh-cn/quick-start/)操作。

## 当前支持范围

阿里云 ECS 安全组、一个配置好的 TCP 端口、精确公网 IPv4 授权。控制面使用 Cloudflare Workers 与 SQLite Durable Objects。v0.2 不包含 Terraform 或其他云适配器。
