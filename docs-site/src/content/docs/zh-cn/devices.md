## 创建设备密钥

在客户页面“让设备随网络自动更新”中填写名称，点击“创建设备密钥”，将一次性显示的密钥存入密码管理器。网页登录仍使用原客户访问令牌。

设备密钥只能为该设备观测到的来源续期。服务器忽略刷新请求体中主动指定的来源。默认租约 60 分钟，脚本每五分钟续期一次。切换网络时，旧地址默认宽限 120 秒，且不超过原授权有效期。

## macOS

从自己的专属入口下载 macOS / Linux 脚本。下载内容会使用当前界面语言。阅读脚本后运行：

```sh
bash update-ip.sh --setup
```

在隐藏提示中粘贴设备密钥。脚本保存仅当前用户可读的 curl 配置，并安装五分钟运行一次的用户 LaunchAgent。不同服务入口在 `~/.config/port-allowlist/` 下使用独立配置目录和独立任务名称；密钥不会进入进程参数。

需要立即更新时，再运行一次脚本即可。卸载前先在网页撤销设备，再卸载对应的 `org.port-allowlist.update-ip.*` LaunchAgent，并删除该服务的配置目录。

## Linux

相同安装命令会保存私有密钥，但不自动安装定时任务。请用 cron 或用户 systemd timer，每五分钟执行一次安装后的脚本；安装命令会输出路径。在 `crontab -e` 中填写实际绝对路径：

```cron
*/5 * * * * /bin/bash <absolute-installed-script-path> >/dev/null 2>&1
```

保存前替换占位符，仅向需要运行任务的用户授予脚本与密钥读取权限。删除任务与配置前，请先在网页撤销设备。

## Windows

从客户页面下载并检查 Windows 脚本，然后在 PowerShell 执行：

```powershell
powershell -File update-ip.ps1 -Setup
```

脚本提示输入设备密钥，以绑定当前用户的 DPAPI 加密保存，并创建每五分钟运行一次的当前交互用户任务；不会改变机器级执行策略。后续请使用同一 Windows 账户。撤销设备后，可删除对应的 `PortAllowlist-UpdateIP-*` 计划任务和配置目录。

Windows 实机计划任务验收仍待完成。已测试脚本交付与语言选择，不将其等同于 Windows 运行验收。

## 网络与排错

脚本使用 IPv4 HTTPS，配置明确超时，不跟随重定向。为观测设备直接 IPv4 路径，会绕过环境 HTTP 代理；系统 VPN 仍可能决定实际出口。网络无可用 IPv4 时，需要手动登记或切换网络。

设备离线后，**运行正常的同步器处理到期授权时**才会撤销已过期规则。Agent 停止后，已下发的云规则不会自行到期，见[故障行为](../security/)。

密钥错误可能表示设备已撤销、客户被停用或使用了错误的入口。不要将令牌、私有配置或真实来源地址粘贴到公开 Issue；只分享脱敏后的稳定错误码和平台版本。
