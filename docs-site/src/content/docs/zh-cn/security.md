## 权限边界

一个部署只管理一个 ECS 安全组中的一个由管理员预先配置的 TCP 端口。客户不能提交端口、安全组 ID、地域或阿里云凭据。只有 ECS 本地 Agent 持有云凭据，目标由本地配置固定，允许调用的 ECS 动作仅有查询规则、添加入站规则和撤销入站规则。

Worker 保存客户 / 设备令牌哈希，以及管理员 / Agent 令牌哈希和会话令牌哈希。原始密钥只在签发时展示，或保留在操作者私有初始化文件中。

客户域名与客户在服务端绑定，客户入口无法调用运营 / Agent 接口。客户令牌不能读取其他客户的授权，也不能登录管理员域名；设备令牌只能更新自身的当前来源。浏览器会话使用 HttpOnly、Secure、SameSite=Strict Cookie，并对写请求检查同源。Bearer token 必须作为凭据保护；轮换客户令牌会使其旧浏览器会话失效。

## 配额与规则归属

整个部署默认最多 180 个不同的有效地址，为 Agent 的 200 条策略校验上限留出余量。真实云配额可能更小，且包括非本项目规则，应先在目标账号核对。客户额度统计授权和已委托的历史来源规则；一条网段规则按一条规则计算，不按其全部地址数量计算。云 API 异常不能作为扩大访问范围的理由。

新规则固定为目标端口 TCP 入站精确地址，使用项目专属描述前缀和规范地址哈希标识。协调器先添加并确认新规则，再移除过期的项目自有规则。格式错误、超量或端口不匹配的策略会在修改云规则前被拒绝。缓存策略中的授权也保留原到期时间，不会自动延长。

非本项目规则默认保留。管理员可将这个端口的现有规则独占委托给一个客户，允许其按规则清单发起明确删除请求。SHA-256 指纹绑定规则 ID、方向、协议、端口、来源、优先级和描述；变化后的规则不能通过旧指纹删除。删除已选历史网段前，会先为仍需要的有效授权建立精确替代规则。跨端口范围的规则永远不能通过此流程删除。

云 IAM / RAM 是独立边界。攻击者若取得底层云凭据，不能指望 Python 应用中的端口校验限制其能力。请按[部署说明](../deployment/)核对最小权限和资源范围。

## 故障时会怎样

| 情况                          | 行为                                             |
| ----------------------------- | ------------------------------------------------ |
| 控制面超时                    | 用最后一份已验证缓存策略继续处理，保留原到期时间 |
| 没有有效缓存                  | 不修改云策略                                     |
| 添加失败或未确认              | 保留旧访问，不继续删除                           |
| Agent、主机、网络或凭据不可用 | 云规则保持原状，不会自行到期                     |
| 非本项目历史规则              | 保留原生命周期，直到明确请求删除                 |
| 已建立 TCP 连接               | 可能受连接跟踪保留，不承诺立即断开               |

因此，要求严格到期时必须独立监控 Agent、过期策略、凭据轮换和恢复通道。其他附加安全组或历史宽泛规则也可能继续放行流量，需要审查组合策略。撤销应使用新连接验收；应用会话主动终止不在本项目范围内。

## IP 身份与观测数据

白名单授权的是公网出口，不是一个人。共享 NAT / VPN 的设备共享网络访问边界，业务服务仍需自己的认证与加密。

客户活动按其当前获准的来源过滤。共用出口的用户可能看到同一来源级活动，不能将其作为严格的个人 / 设备流量账单。`ss` 字节差分只代表可观测 socket，不是云计费或业务端到端健康。图示为逻辑拓扑，连线流动只表示观测到连接。

产品运行时会在 Cloudflare 存储来源地址及审计数据：会话事件保留 7 天、审计保留 30 天、采样保留 1 天，清理按小时运行。授权和规则清单记录会保留，直到管理员维护或删除数据库。Agent 本地状态与可选日志也包含地址，应限制读取并配置轮转。公开仓库不包含生产清单、客户域名、实际地址或部署凭据。

## v0.2 浏览器与演示隔离

localStorage 只存语言和外观偏好，不存客户或设备原始令牌。一次性设备密钥在弹窗关闭后从 UI 状态清除。客户备注按 React 文本渲染，不解析 HTML。所有授权变更仍需服务端校验；隐藏管理员按钮不构成鉴权。

静态演示使用独立内存传输层、掩码的生成地址和示意密钥，不调用生产 API，不保存云凭据，不安装任务，不改防火墙。每个页面都有模拟数据标识；刷新或重置会清空改动。演示图表和同步状态是模拟效果，不能用来证明生产服务正常。

API 错误码与受限参数可以在核对后分享；云端原始诊断、凭据和私有标识不会作为客户错误文案返回。

## 当前限制与问题报告

仅支持 IPv4 / TCP、每部署一个阿里云安全组；不自动刷新 STS 凭据；Agent 停止时不保证规则按时失效；不清理其他安全组，不强制中断已建立会话。Windows 实机计划任务验收仍待完成。本地测试使用生成数据和模拟云 Provider，每次新部署都需独立执行真实增删与服务保全验收。

安全问题请通过仓库所有者的私密渠道，或已开启的 GitHub 私密安全报告提交。不要在公开 Issue 上传可用凭据、地址、客户资料或完整请求体。
