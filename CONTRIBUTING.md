# Contributing

Use the Node.js version in `.nvmrc` (22.23.4+) and Python 3.10+. `npm ci` installs locked portal and documentation dependencies. Run the commands in the README before submitting a change. CI builds and tests the portal, agent, bilingual documentation and isolated demo. Only a verified main-branch build publishes static documentation to GitHub Pages; it never deploys the production Worker or applies ECS rules.

The application lives in `web/` (typed React components, shared store, translations and HTTP/demo transports). Worker routes are in `src/`; stable safe error codes are in `shared/errors.ts`. The ECS synchronizer is in `agent/`. Documentation is maintained once, as matched pages in `docs-site/src/content/docs/en/` and `zh-cn/`. `docs/*.md` compatibility links point to that source. Public screenshots are generated from the labeled, masked demo and stored once in `docs/screenshots/`.

Run `npm run format` for the new frontend and documentation sources, then `npm run format:check`. Add English and Chinese entries together, preserving interpolation parameters. `npm run check:content` checks all labels, error messages, paired pages, links and documented npm commands. The static site test additionally checks built assets and anchors, search, language navigation, demo isolation, mobile widths and accessibility.

Preserve the fixed-port / fixed-group boundary, add-before-delete ordering, original cached expiries, tenant isolation, explicit existing-rule deletion and owner-only credential files. Changes to these guarantees need meaningful regression tests. UI polling must preserve drafts, focus, scroll and expanded groups; a network or agent error must never be represented as confirmed application health.

Do not include live tokens, addresses, personal / customer names, domains or cloud IDs in fixtures, screenshots, issues or commits. Use example.com and generated synthetic address fixtures. The demo masks addresses and must not call a real API. Stage files deliberately, run `npm run audit:public`, then a redacting secret scanner before publishing. Never copy `.local`, local state, cloud CLI profiles, agent environment files, logs or production history into the repository.
